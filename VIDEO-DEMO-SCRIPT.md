# BigBasket Actor Demo Script

Target length: 30-45 seconds.

## Voiceover and screen sequence

1. **Actor page (0-5 seconds)**
   "This BigBasket Grocery Scraper exports public product prices, MRP, discounts, pack sizes, ratings, stock status, and source URLs."

2. **Input form (5-13 seconds)**
   "Enter a grocery keyword or category page, choose an optional brand filter, and keep the first run small."

3. **Start run (13-20 seconds)**
   "The default workflow uses an India residential proxy because BigBasket availability and pricing are regional."

4. **Dataset output (20-31 seconds)**
   "Each saved row is structured for CSV, Excel, JSON, API, or a scheduled monitoring workflow."

5. **Saved task and schedule (31-40 seconds)**
   "Save the input as a task, schedule it daily, and send successful datasets to Google Sheets or your webhook automation."

6. **Closing frame (40-45 seconds)**
   "Start with the public example on Apify and expand only after the output matches your use case."

## Recording notes

- Use a one-result first run so the recording stays fast and inexpensive.
- Show the `Products` dataset view and one complete row.
- Do not show API tokens, cookies, personal accounts, or unrelated browser tabs.
- Add captions and link the Actor in the video description.
